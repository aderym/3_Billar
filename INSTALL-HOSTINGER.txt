OSP BILLIARDS PLAY — INSTALACION COMPLETA EN HOSTINGER

ESTE ZIP ES UNA APLICACION NODE.JS, NO UN SITIO ESTATICO.
No subas solamente public/ a public_html ni uses un .htaccess que
redirija /api hacia public/: la API de login y torneos necesita Node.js.

1. En Hostinger crea una aplicacion Node.js (o un sitio Node.js en tu VPS).
   Necesitas Node.js 22.13 o posterior y almacenamiento persistente.

2. Extrae TODO el ZIP en la carpeta raiz de la aplicacion. En esa carpeta
   deben quedar package.json, public/, server/, worker/ y schema/ al mismo nivel.
   No hace falta npm install: no hay dependencias externas.

3. Configura el comando de inicio como: npm start
   Alternativa: node server/index.mjs
   Si Hostinger asigna PORT, el servidor lo lee automaticamente; en un VPS
   puedes definir PORT=3000. Conecta el dominio a ESTA aplicacion Node.js
   desde Hostinger. No establezcas public/ como aplicacion separada.

4. Configura OSP_DATA_DIR con una carpeta persistente y escribible, fuera
   del directorio publico. Si no la configuras, se crea storage/ dentro
   de la carpeta de la aplicacion. Haz copia de seguridad de esa carpeta.

5. Antes del primer login, abre una terminal en la raiz de la aplicacion
   y ejecuta: npm run setup
   Escribe el nombre del local, nombre de admin, usuario y contrasena.
   El programa no incluye credenciales por defecto. La contrasena se ve
   mientras la escribes en la terminal: usa una terminal privada.

6. Comprueba estas rutas con el dominio ya conectado:
   /health          -> OK
   /api/session     -> JSON, por ejemplo {"account":null} sin login
   /api/setup       -> JSON

   Si /api/session empieza con <!DOCTYPE, Hostinger esta sirviendo HTML
   en vez de enviar las peticiones al servidor Node.js. Revisa que el
   proceso este iniciado y que el dominio apunte a la aplicacion Node.

El despliegue previo de ChatGPT Sites y esta instalacion tienen bases de
datos distintas: sus usuarios, contrasenas y torneos no se transfieren
automaticamente. El DNS de billar.osprestabar.com debe apuntar a la
aplicacion Hostinger si quieres servir desde Hostinger; no puede apuntar
al mismo tiempo al despliegue de ChatGPT Sites.
