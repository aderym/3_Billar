OSP Billiards Play v49 — complete Hostinger/VPS application. OSP owner can manage each venue name and logo, create administrators and players, edit the team accounts (name, username, email, phone, password, active status and primary administrator) and upload/remove their photos. Venue labels persist when tournaments change. Owner-only routes enforce venue isolation. Existing tournament and payment history is retained. Deploy code files, preserve storage/ and billing.key, restart Node. Do not run setup on an existing installation. See INSTALL-HOSTINGER.txt.
